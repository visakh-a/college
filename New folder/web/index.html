⚙️ Methodology & Architecture

  • Data Extraction: CEE Kerala KEAM 2026 Phase 2 Allotment Cutoff ranks across 54+ pages.
  • Java Backend: Core Java OOP models, multi-criteria filtering, and RESTful API endpoints.
  • Prediction Engine: Probability scoring algorithm categorizing colleges into Safe, Target, and Reach.
  • Nearby Colleges: Graph-based distance & district adjacency model across Kerala's 14 districts.
